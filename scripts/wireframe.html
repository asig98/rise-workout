State & data flow

The store — routine · todayPlan · restDays · today · history, persisted to localStorage["rise-v2"]. Same key and shape as the pre-React app, so existing users keep their history.

Derived, never stored — level, streaks, best week/month, badges, heatmap intensity. All pure functions of (history, restDays), memoised.

Deliberately local — timer and player countdowns. At 1Hz in the store they would re-render 84 heatmap cells every second for a number one overlay displays.

Events go up — ExerciseRow onToggle(id) → ExerciseList → TodayView → dispatch → every consumer re-renders from one source. Confetti, haptics and toasts fire in the handler, so the reducer stays pure.
